Instal SMB Remastered

Ikuti langkah-langkah berikut untuk memasang aplikasi dan memilih file game Super Mario Bros.

📦 Siapkan 2 file terlebih dahulu

Pastikan kedua file sudah diunduh dan tersimpan di HP sebelum memulai instalasi.

📱
SMB Remastered AndroidFile aplikasi Android (.APK)
🎮
Super Mario Bros.nesFile game / ROM (.nes)
1

Unduh file APK dan ROM

Unduh file SMB Remastered Android dan Super Mario Bros.nes ke HP.

  • Ingat lokasi penyimpanan file, biasanya folder Download.
  • Jangan mengubah nama atau memindahkan file ROM setelah diunduh, agar mudah ditemukan nanti.
2

Izinkan instalasi APK

Jika HP meminta izin, buka pengaturan untuk mengizinkan pemasangan aplikasi dari sumber tersebut.

  1. Buka Pengaturan HP.
  2. Masuk ke Keamanan & Privasi atau menu serupa.
  3. Pilih Install aplikasi yang tidak dikenal / Instal aplikasi tidak dikenal.
  4. Pilih aplikasi yang digunakan untuk membuka APK, misalnya File Manager atau browser.
  5. Aktifkan Izinkan dari sumber ini hanya jika kamu yakin file berasal dari sumber tepercaya.

Nama menu dapat berbeda tergantung merek HP dan versi Android.

3

Instal aplikasi

  1. Buka File Manager di HP.
  2. Masuk ke folder Download atau lokasi file APK disimpan.
  3. Ketuk file SMB Remastered Android (.apk).
  4. Ketuk Instal dan tunggu hingga selesai.
  5. Setelah berhasil, buka aplikasi game tersebut.
4

Verifikasi dan pilih file ROM

  1. Saat aplikasi menampilkan tulisan ROM VERIFICATION REQUIRED, ketuk layar.
  2. Jendela pemilih file akan terbuka. Cari file Super Mario Bros.nes.
  3. Jika file berada di folder Download, buka folder tersebut.
  4. Pilih file Super Mario Bros.nes, lalu konfirmasi jika diminta.
  5. Tunggu proses verifikasi. Jika berhasil, ikuti petunjuk di aplikasi untuk mulai bermain.

✅ Sebelum mulai bermain

  • Aplikasi SMB Remastered Android sudah terinstal.
  • File Super Mario Bros.nes masih tersimpan di HP.
  • File ROM sudah dipilih saat proses verifikasi.

Tips: Jika file ROM tidak ditemukan, periksa folder Download atau gunakan fitur pencarian di File Manager dengan kata kunci Super Mario Bros.
